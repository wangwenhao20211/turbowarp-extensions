# 图层管理器

打开一个浮动面板，通过拖拽列表实时调整角色图层顺序。

## 功能

- 一键打开浮动面板，列出项目中所有原始角色
- 列表顺序与舞台上的图层顺序完全一致（从底到顶）
- 通过拖拽每个角色左侧的把手，实时调整它在列表中的位置
- 松手后舞台上的图层遮挡关系立即更新
- 支持鼠标拖拽和触摸屏拖拽
- 拖拽到列表上下边缘时，列表会自动滚动
- 面板本身可以拖动，放置在屏幕任意位置
- 点击「刷新」按钮，可从舞台重新读取当前图层顺序

## 积木说明

| 积木 | 类型 | 作用 |
|------|------|------|
| `打开图层管理器` | 命令 | 在舞台上打开图层管理浮动面板 |

## 使用示例

在绿旗被点击时打开面板：

```
当绿旗被点击
打开图层管理器
```

打开面板后：

1. 面板会列出所有角色，列表**最上方是最顶层**，**最下方是最底层**。
2. 按住某个角色左侧的 `⋮⋮` 把手上下拖动。
3. 拖拽时其他角色会自动让位，靠近列表上下边缘时列表会自动滚动。
4. 松手后，舞台上角色的遮挡顺序会立即按照列表顺序更新。

如果你在脚本里用其他积木改变了图层顺序（比如 `移到最前面`），点击面板工具栏上的「刷新」按钮即可同步显示最新顺序。

## 注意事项

- 本扩展为**非沙盒扩展**，网页版 TurboWarp 编辑器**无法加载**。
- 请使用 **TurboWarp 桌面版**，并在设置中开启「运行未沙盒化扩展」。
- 或者通过 **TurboWarp Packager** 打包为 HTML / exe 后使用。
- 面板仅在编辑器和打包后的项目中显示；如果用 `go to front` 等积木改变图层，面板不会自动同步，需手动点「刷新」。

## 已知限制

- 只列出**原始角色**，不包含舞台和克隆体。
- 克隆体的图层跟随本体，无法单独管理。
- 刷新时通过渲染器绘制列表读取顺序，如果角色刚被添加还未来得及渲染，可能会被排到列表末尾。
- 面板位置固定在屏幕坐标上，不会随舞台缩放而移动。
