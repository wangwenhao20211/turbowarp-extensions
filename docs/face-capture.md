# 面部捕捉

用摄像头实时捕捉面部动作，输出头部姿态、眼睛开合、嘴型等数据，可以驱动角色、舞台效果或做出「摇头点头眨眼」这类互动。

## 功能

- 纯浏览器本地运行，画面不上传，隐私安全
- 实时输出头部三轴角度（上下 / 左右 / 倾斜）
- 输出左右眼开合度，可用于眨眼检测
- 输出嘴型 A/E/I/O/U 权重，可驱动口型动画
- 首次加载有进度弹窗，加载完成后自动消失
- 30 FPS 稳定检测，主线程不卡顿

## 积木说明

| 积木 | 类型 | 作用 |
|------|------|------|
| `启动面部捕捉` | 命令 | 请求摄像头权限并开始检测，首次加载会弹进度窗 |
| `停止面部捕捉` | 命令 | 关闭摄像头，释放资源 |
| `正在运行？` | 布尔 | 检测是否正在运行 |
| `检测到人脸？` | 布尔 | 当前帧是否识别到人脸 |
| `头部 上下（抬头为正）` | 报告 | 头部俯仰角，抬头变大，低头变小 |
| `头部 左右（左转为正）` | 报告 | 头部偏航角，左转变大，右转变小 |
| `头部 倾斜（右歪为正）` | 报告 | 头部翻滚角，向右歪变大 |
| `头部位置 X` | 报告 | 面部中心的原始位置值，不做映射 |
| `头部位置 Y` | 报告 | 同上 |
| `左眼开合 0~1` | 报告 | 1 完全睁开，0 完全闭合 |
| `右眼开合 0~1` | 报告 | 同上 |
| `正在眨眼？` | 布尔 | 双眼开合度都低于 0.4 时为真 |
| `嘴巴张开程度` | 报告 | 越大嘴张得越开 |
| `嘴巴横向偏移` | 报告 | 正负表示嘴角左右偏向 |
| `嘴型 [A]` | 报告 | 元音口型权重，可选 A/E/I/O/U |
| `调试信息` | 报告 | 打印当前位置、角度等原始数值，用于排查问题 |

## 使用示例

最小可用脚本：

```
当绿旗被点击
启动面部捕捉

重复执行
  如果 <检测到人脸？> 那么
    将 [头上下] 设为 (头部 上下（抬头为正）)
    将 [头左右] 设为 (头部 左右（左转为正）)
    将 [眨眼] 设为 (左眼开合 0~1)
    将 [张嘴] 设为 (嘴巴张开程度)
```

眨眼触发动作：

```
当绿旗被点击
启动面部捕捉

重复执行
  等待直到 <正在眨眼？>
  说 [你眨眼了！] 持续 0.5 秒
  等待 1 秒
```

口型动画：

```
当绿旗被点击
启动面部捕捉

重复执行
  将造型切换为 (嘴型 [A]) 最近的造型
  // 或根据嘴型 A/E/I/O/U 五个值加权混合
```

## 注意事项

- 本扩展为**非沙盒扩展**，网页版 TurboWarp 编辑器无法加载
- 请使用 TurboWarp 桌面版，并在「设置 → 高级」中开启「运行未沙盒化扩展」
- 或者用 TurboWarp Packager 打包成独立 HTML / EXE 后使用
- 加载时需要访问 jsDelivr CDN，请确保网络能访问 `cdn.jsdelivr.net`
- 首次加载约 5~10 MB 模型文件，之后会被浏览器缓存，二次启动很快
- 摄像头权限必须允许，否则无法启动

## 已知限制

- **头部角度范围偏小**：正脸时接近 0，大幅转头也只有几十度，建议在 Scratch 里乘以一个放大系数
- **头部位置是原始值**：不同摄像头、不同距离下数值范围不同，没有统一映射，需要自己归一化
- **眼睛检测依赖人脸大小**：脸离摄像头太远或光线太暗时，眼睛开合可能一直停在 1 附近，建议保持 30~50 cm 距离、光线充足
- **同时只检测一张人脸**：画面里有多人时只追踪置信度最高的那张
- **上游许可为非商用**：本扩展复用了 [zkcpku/live2d-face-release](https://github.com/zkcpku/live2d-face-release) 的部分代码，请勿用于商业用途
